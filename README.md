# Rosalind Solutions

This repository contains my solutions to the bioinformatics computational challenges on **[Rosalind](https://rosalind.info)**.

As a first year Computer Science student, I am using these challenges to improve my understanding of dynamic programming, string manipulation, graph theory and raw data parsing.

**Language - Python 3.14**

**Environment - VSCode**

# Repository Structure

```
|-- README.md               # Repository documentation
|-- Stronghold/             # Rosalind bioinformatics stronghold track solutions
    |-- Counting_DNA_Nucleotides.py        # Algorithm for counting the number of times nucleotides occur in a string
    |-- Transcribing_DNA_Into_RNA.py        # Algorithm for translating each consecutive nucleotide in a string to it's corresponding RNA value
    |-- Complementing_A_Strand_Of_DNA.py        # Algorithm for calculating the reverse compliment of a DNA string
    |-- Rabbits_and_Recurrence_Relations.py        # Algorithm for calculating the growing population of rabbits using a Fibonacci sequence
    |-- Computing_GC_Content.py        # Algorithm for calculating the highest GC content DNA strand given a FASTA format flatfile of DNA strands
    |-- Counting_Point_Mutations.py        # Calculates the number of Nucleotide mutations give the before and after string of DNA
    |-- Mendels_First_Law.py        # Algorithm that calculates the probability of a dominant allele offspring given the number of homozygous recessive/dominant and heterozygous organisms that can mate      
```

Rather than approaching the problems as biology challenges, I am using them to practice practical application of data structures and algorithms.
