# Rosalind Solutions

This repository contains my solutions to the bioinformatics computational challenges on **[Rosalind](https://rosalind.info)**.

As a first year Computer Science student, I am using these challenges to improve my understanding of dynamic programming, string manipulation, graph theory and raw data parsing.

**Language - Python 3.14**

**Environment - VSCode**

# Repository Structure

```
|-- README.md               # Repository documentation
|-- Stronghold/             # Rosalind bioinformatics stronghold track solutions
    |-- Counting_DNA_Nucleotides.py        # Algorithm for counting the number of times nucleotides occur in a string
    |-- 
    |-- 
```

Rather than approaching the problems as biology challenges, I am using them to practice practical application of data structures and algorithms.
